# 人生日历 Life Calendar · 设计契约

> Chrome/Edge MV3 新标签页扩展。把 80 年画成一张表：每过一天涂满一格，
> 让人看清已走过的路与剩下的时光。

---

## 1. 设计哲学

- **网格即签名元素。** 80 年 = 80 个年格、一年 = 最多 366 个日格。网格占据画面
  绝对中心，任何装饰（画作背景、SVG 图形、纹理）都必须退居其后，服务于
  「时间流逝」这一主题，绝不喧宾夺主。
- **东西方美学的融合。** 版面是东方的——留白、居中、书卷气的宋体标题与
  大写数字月名；底色是西方的——梵高、北斋、莫奈的经典画作作为氛围层。
- **克制。** 一个屏幕一个焦点；装饰图形只出现在标题下方一处；动效只有
  150–240ms 的状态过渡；无渐变滥用、无 emoji、无花哨投影。
- **耐看不花哨。** 用户每天打开数十次新标签页，设计必须在第一万次观看时
  依然安静得体。

## 2. 色彩系统

所有颜色通过主题数据对象定义，由 `src/lib/theme-css.js` 的 `buildThemeCSS()` 函数
生成 CSS 自定义属性并注入 `<style id="theme-style">`。组件样式引用变量，不写死 hex。

| CSS 变量 | 职责 |
| --- | --- |
| `--text` | 主文字色 |
| `--muted` | 次要文字色（统计行、辅助信息） |
| `--page-bg` | 页面底色 |
| `--card-bg` | 日历卡片、弹窗底色（经 glass 调制 alpha） |
| `--cell-line` | 网格线 / 边框色 |
| `--cell-past` / `--cell-past-text` | 过去格底色 / 文字色 |
| `--cell-future` / `--cell-future-text` | 未来格底色 / 文字色 |
| `--cell-today` | 今天格底色 |
| `--today-glow` | 今天格内阴影光晕（box-shadow，无光晕时为 `none`） |
| `--accent` / `--accent-on` / `--accent-soft` | 强调色 / 其上文字色 / 柔和变体（每日一句用） |
| `--panel-bg` / `--panel-line` | 设置面板底色（取未来格实色）/ 面板分隔线（取格线色） |
| `--glyph-past` / `--glyph-future` / `--glyph-today` | 格子装饰图形（data-URI 背景图） |
| `--card-shadow` | 卡片投影 |

## 3. 字体系统

全部使用系统字体栈，零外部字体文件（满足扩展 CSP）。

| 用途 | CSS 变量 | 字体栈 |
| --- | --- | --- |
| 数字（年份、日号、统计） | `--font-num` | Didot → Bodoni MT → Times New Roman → Songti SC → serif |
| 标题（页标题、月名、引用） | `--font-title` | Songti SC → Noto Serif CJK SC → SimSun → serif |
| UI（按钮、标签、设置） | `--font-ui` | -apple-system → BlinkMacSystemFont → PingFang SC → Microsoft YaHei |

数字字号通过两个 CSS 变量响应式缩放：
- `--num-day-size: clamp(8px, 0.8vw, 11px)` — 日格与月标签角标
- `--num-year-size: clamp(13px, 1.7vw, 23px)` — 年格

其余文字（标题 26px、统计 13px、引用 14.5px、UI 14px 等）直接使用 `font-size` 属性。

## 4. 间距 · 圆角 · 阴影 · 动效

- **页面**：`max-width: 1280px` 居中，`padding: 16px 24px 6vh`。
- **网格**：32 列 CSS Grid（1 月标签列 + 31 天位列）；年格 `grid-column: span 2`，
  年格宽 = 日格宽 × 2，上下严格对齐；单元格间隙由 1px border 实现。
- **圆角**：格边 2.5px · 按钮 8–9px · 卡片 14px · 弹窗/遮罩 16px · 进度条全圆。
- **阴影**：仅卡片投影 `--card-shadow: 0 2px 18px rgba(0,0,0,0.15)`（由主题生成），
  弹窗使用 `0 12px 48px rgba(0,0,0,0.18)`。
- **毛玻璃**：由 `buildThemeCSS()` 根据 `settings.glass`（0–100）实时计算。
  50 = 主题原始透明度；< 50 趋向实底（alpha 向 1 插值）；> 50 趋向透明磨砂
  （降低 alpha + 增加 `blur` + `saturate`），通过 `.card` 的 `backdrop-filter` 实现。
- **动效**：150ms `cubic-bezier(.2,0,0,1)` 过渡，用于主题切换、悬停、保存提示。
- **焦点**：`:focus-visible` 时 `outline: 2px solid var(--accent)` + `outline-offset: 2px`。

## 5. 组件规范

### 5.1 顶部信息区
- **主题栏**（`#theme-bar`）：左侧 pill 按钮组，显示全部主题（预制 + 自定义），
  当前主题高亮为 accent 填充。点击即可切换。
- **标题块**（居中）：标题上方装饰图形三连（过去色 / 今天色 / 未来色，无图形主题隐藏）
  → 标题（昵称 +「的人生日历」）→ 统计行（已度过 X 天 · 剩余 Y 天 · 生命进度 Z%）
  → 每日一句（可开关）→ 历史上的今天（可开关，无事件自动隐藏）。
- **右上角操作区**：语言切换按钮（`文/A` SVG 图标）→ 下拉菜单（5 语言，当前项显示 accent 勾）
  → 齿轮设置按钮（悬停旋转 30°）。

### 5.2 人生进度条
80 段 10px 高细条（含 2px padding），`flex` 等分布局。已过年份填充 `--accent`，
今年段内嵌比例填充，未来段为 `--cell-line` 色（opacity 0.55）。

### 5.3 日历卡片
- **年份网格**：5 行 × 16 列 = 80 格，与月份网格共享 32 列 CSS Grid。年格
  `grid-column: span 2`。格内：年份数字（大，`--font-num`）+ 年龄小字（可关，
  opacity 0.62）。过去年填 `--cell-past`，今年格 accent 描边 + 底部 3px 年度进度条。
  含一次性里程碑的年份右上角 5px accent 圆点。点击选中切换月份网格年份，再点回到今年。
- **月份网格**：12 行 × 32 列（1 标签 + 31 天位）。不足 31 天的行自然结束。
  月标签格：右下角小号角标数字（1–12）+ 中部月名（中文大写数字 / 日文和风月名竖排 /
  英韩三字母缩写），当月红字。
- **日格**：aspect-ratio 1:1，过去 / 未来 / 今天三态配色。右下角小号日号（可关；
  默认主题无图形时居中放大）。装饰图形通过 `--glyph-*` 背景图注入。里程碑日在格子
  中央显示图标（蛋糕/戒指/旗帜/星星/爱心），同时隐藏主题底纹。
- **Tooltip**：悬停日格使用原生 `title` 属性，内容 = 日期 + 里程碑标签 + 历史上的今天条目。

### 5.4 首次使用引导
居中遮罩弹窗（`backdrop-filter: blur(6px)`）：标题 + 描述 + 出生日期输入 +「开始」。
白底卡片强制 `color-scheme: light`（避免暗色主题下原生日期控件图标不可见）。
提交后持久化出生日期并渲染主页面。设置中可重新打开。

### 5.5 设置弹窗
悬浮遮罩（`rgba(24,24,24,0.28)` 半透明，后方页面清晰可见），弹窗底色取
`--panel-bg`（未来格色）。分组：
- **基本**：昵称（防抖保存）/ 出生日期 / 时区（自动检测 + 手动选择）/ 主题（下拉 +
  三色块预览 + 编辑 / 另存为 / 新建 / 删除按钮）
- **显示**：年龄开关 / 日号开关 / 每日一句开关 / 历史上的今天开关 / 背景图开关 +
  毛玻璃滑杆（实时预览）
- **重要日期**：列表（日期 + 图标 + 标签 + 删除） + 添加表单（日期选择 + 事件名 +
  每年重复勾选 + 图标选择器 + 添加按钮）
- 底部：「重新引导」和「完成」按钮 + 版本号（`v{version} · Manifest V3`）

### 5.6 主题编辑器
独立遮罩弹窗（`backdrop-filter: blur(4px)`），白底卡片强制 `color-scheme: light`。
编辑项：名称（最多 6 字）/ 格子图形（无/灯泡/浪花/禾苗/音符）+ 三态颜色 / 背景图
（上传 + 预览 + 清除，canvas 压缩 1920px JPEG 0.72）/ 顶部遮罩（无/浅色/深色）/
11 个颜色字段 + 今天格光晕开关 / 4 个不透明度滑杆。保存时自动将上传图写入
`chrome.storage.local`。

## 6. 装饰图形（来自 src/lib/glyphs.js）

装饰图形是参数化 SVG，按颜色生成 data-URI 注入 `--glyph-*` CSS 变量。日格自动显示，
无需 DOM 操作。`today` 状态可使用填充变体（如灯泡点亮）。

- **灯泡（bulb）**：灯座 + 灯泡轮廓，today 变体为实心填充
- **浪花（wave）**：两条波浪线（主线 + 淡线），无填充
- **禾苗（sprout）**：双叶一茎，实心填充
- **音符（note）**：椭圆符头 + 符干，实心填充

## 7. 主题切换机制

主题系统采用**数据驱动管线**，不使用静态 CSS 文件或 `[data-theme]` 属性选择器：

```
主题数据对象（src/lib/theme-presets.js 预制 / settings.customThemes 自定义）
  → src/lib/theme-css.js buildThemeCSS(theme, bgUrl, glass) 生成完整 CSS 文本
  → 注入 <style id="theme-style">，覆盖 :root 下所有变量
```

- `body.dataset.theme` 设为主题 id（或 `'custom'`），仅用于无图形主题的日数字居中判断
- `body.dataset.glyph` 设为图形类型名，CSS 据此调整格子布局
- 背景图 URL 在调用 `buildThemeCSS()` 前异步解析（builtin 用包内路径，upload 从
  `chrome.storage.local` 读取 dataURL，失败则回退纯色）

## 8. 响应式与可访问性

- 页面 `max-width: 1280px` 居中，窄屏（≤720px）收紧留白、缩小标题。
- 触控目标：主题 pill、设置齿轮、语言按钮、年格均可点；日格密度高，属只读信息格。
- 键盘：所有可交互元素 `:focus-visible` 显示 accent 色焦点环；Esc 关闭弹窗/菜单；
  设置弹窗和主题编辑器使用 `role="dialog"` + `aria-modal="true"`；
  语言菜单使用 `role="menu"` + `role="menuitemradio"` + `aria-checked`。
- 暗色主题：底色亮度 < 0.35 时声明 `html { color-scheme: dark; }`，
  让滚动条与原生控件匹配。
- 主题编辑器和引导弹窗强制 `color-scheme: light`，防止暗色主题下原生日期控件不可见。
